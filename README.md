# CidadeConecta

Sistema para o cidadão notificar problemas urbanos (buracos, iluminação, etc.) à prefeitura de Ji-Paraná, com acompanhamento de status e painel administrativo para as secretarias.

Projeto composto por duas partes: `backend` (API) e `frontend` (interface web).

## Pré-requisitos

- Node.js 18 ou superior
- PostgreSQL instalado e rodando

A aplicação abre em `http://localhost:5173`.
